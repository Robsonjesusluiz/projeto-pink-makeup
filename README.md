# 🎀 Pink-Makeup — Artigo-Luxuria & Acessórios-Premium
<img src="https://github.com/Robsonjesusluiz/projeto-pink-makeup/blob/main/img/pink%20makeup%20note%20e%20pc.png?raw=true">
Uma plataforma de e-commerce e catálogo digital elegante e responsiva, desenvolvida sob medida para a **Pink-Makeup**, especializada na vitrine de semijoias de alta joalheria, maquiagens, kits de autocuidado e acessórios de luxo.

## 📋 Sobre o Projeto

Este projeto consiste em uma página web dinâmica e altamente visual voltada para a conversão e experiência do usuário (UX). O layout foi estruturado com foco em um design atraente, apresentando coleções temáticas com descrições detalhadas baseadas em engenharia de produto, acabamentos premium e tecnologia hipoalergênica. A página serve como um catálogo interativo conectado diretamente a canais de atendimento para fechar vendas.

## 🛠️ Tecnologias Utilizadas

O projeto foi construído utilizando as seguintes ferramentas:

*   **HTML5** - Estruturação semântica de seções de produtos e metadados.
*   **CSS3 / Tailwind CSS** - Estilização moderna, layouts em grade (Grid/Flexbox) e responsividade para dispositivos móveis.
*   **JavaScript** - Manipulação de interações na vitrine e redirecionamentos.

## ✨ Funcionalidades e Seções Catalogadas

A página organiza com precisão cirúrgica uma ampla variedade de produtos divididos em categorias estratégicas:

*   **🛍️ Queridinhos do Momento:** Seção dedicada a kits de Body Splash aromáticos (Puro Leite, Puro Caramelo e Choco) e caixas afetivas de cuidados pessoais (`Box Love & Care`).
*   **🔥 Tendências Fashionistas & Alta Moda:** Exibição detalhada de correntaria moderna, Chokers (`Elo Grumet Gold`, `Silver`), Mix de colares em camadas e peças geométricas baseadas em conceitos internacionais.
*   **🍀 Linhas de Inspiração de Grifes:** Espaço dedicado a reinterpretações clássicas de alta joalheria, como as linhas estilo *Alhambra (Van Cleef)*, *Angelic (Swarovski)* e *Icon Signature (Valentino)*.
*   **⏱️ Kits Completos e Relógios de Luxo:** Combinações prontas de relógios clássicos com braceletes rígidos, anéis cravejados e pulseiras em camadas.
*   **💫 Coleções Esculturais & Texturas:** Brincos e argolas em aço inoxidável 316L com acabamentos tridimensionais (efeito martelado, frisado e matelassé).
*   **🟢 Detalhamento Técnico Comercial:** Cada produto exibe seus diferenciais de fabricação (lapidação de zircônias, banho premium de Ródio Branco/Ouro, verniz suíço de proteção e tecnologia 100% hipoalergênica).
*   **📲 Integração para Vendas:** Botão de chamada para ação (CTA) integrado diretamente para contato comercial via WhatsApp.

## 🚀 Como Executar o Projeto Localmente

1. **Clone este repositório:**
   ```bash
   git clone https://github.com
   ```

2. **Navegue até a pasta do projeto:**
   ```bash
   cd pink-makeup
   ```

3. **Abra o arquivo principal:**
   Basta abrir o arquivo `index.html` diretamente em qualquer navegador web, ou utilizar a extensão *Live Server* no VS Code para visualizar em tempo real.
